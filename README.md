# GoHéritage

Kirby CMS site for cultural heritage documentation and 3D project visualization.

## Setup

```bash
composer install
npm install
npm run dev
```

## Stack

- **CMS**: Kirby 5
- **Frontend**: Tailwind CSS, Three.js (3D viewer)
- **Build**: Parcel
- **Maps**: MapLibre GL

## Structure

- `/content` — CMS pages and projects
- `/site/templates` — Page templates
- `/site/snippets` — Reusable components
- `/assets` — CSS, JS, logos
